# Monopoly Bank 0.1

Локальный прототип цифрового банка для настольной «Монополии»:
Arduino Nano + RDM6300 (125 kHz UART) + Python + Streamlit + SQLite.

## 1. Подключение RDM6300 к Arduino Nano

| RDM6300 | Arduino Nano |
|---|---|
| VCC | 5V (проверьте маркировку модуля) |
| GND | GND |
| TX | D2 |
| RX | Не подключать |

Arduino Nano USB подключается к компьютеру. В Arduino IDE выберите плату и порт, загрузите `arduino/rdm6300_reader/rdm6300_reader.ino`.

RDM6300 обычно работает с RFID-картами 125 kHz семейства EM4100/EM4102. Карты MIFARE 13.56 MHz не подходят.

## 2. Установка приложения

Рекомендуется Python 3.10+.

```bash
python -m venv .venv
```

Windows:
```powershell
.venv\Scripts\activate
```

macOS/Linux:
```bash
source .venv/bin/activate
```

Установка зависимостей:
```bash
pip install -r requirements.txt
```

Запуск:
```bash
streamlit run app.py
```

Откройте адрес, который покажет Streamlit (обычно http://localhost:8501).

## 3. Использование

1. Прошейте Arduino.
2. Закройте Serial Monitor в Arduino IDE (один COM-порт нельзя одновременно открыть в двух программах).
3. Запустите Streamlit.
4. В боковой панели выберите COM-порт Arduino и нажмите «Подключить».
5. Создайте партию.
6. На вкладке «Игроки» добавьте участников и привяжите карты.
7. Прикладывайте карту к считывателю: UID появится в приложении.
8. Используйте вкладку «Операции» для переводов, сборов, налогов и произвольных платежей.

## 4. Важные ограничения прототипа

- Приложение не определяет положение фишек на поле. Игровые события вводятся вручную.
- Операции с недостаточным балансом отклоняются. Кредиты и залоги пока не реализованы как отдельные обязательства.
- Массовые операции в этой версии выполняются отдельными платежами, а не одной атомарной групповой транзакцией.
- Отмена операции выполняется обратной транзакцией. Если получатель уже потратил деньги, возврат может быть невозможен.
- В приложении пока одна активная партия; архивирование и несколько одновременных партий будут добавлены позже.
- Для настоящей игры используйте резервную копию файла `data/monopoly_bank.sqlite3`.

## 5. Протокол Arduino → Python

После валидного RFID-кадра Arduino отправляет строку:

```text
CARD:0123456789
```

Скорость USB Serial: 9600 baud.

RDM6300 передаёт 14-байтовый кадр: STX, 10 ASCII hex-символов данных, 2 ASCII hex-символа XOR checksum, ETX. Прошивка проверяет кадр и контрольную сумму перед отправкой UID.
